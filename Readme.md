# DevOps Murder Mystery — Case File #001

An interactive, story-driven activity for learning DevOps fundamentals
through a crime investigation game.

![Status](https://img.shields.io/badge/status-active-brightgreen)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

---

## What Is This?

A production server has been hacked. Students play the role of an
**Incident Response Team** and must use real DevOps commands
(Linux, Docker, Git, Kubernetes) to identify the criminal.

The activity combines:
-  **Storytelling** — a narrative drives curiosity
- **Gamification** — teams compete against the clock
- **Hands-on Labs** — real commands on a real filesystem
- **Leaderboard** — visible rankings build engagement
